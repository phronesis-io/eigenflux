# Fidelity validation — October 13, 2026

## Decision and scope

The summary counterexamples pass, the complete captured candidate pools have
been replayed, and the release gate is cleared for enabling both switches for
PGC processing only. UGC extraction and summaries remain unchanged. The consumer
classifies publishers from authoritative database email using `PGC_EMAIL_SUFFIXES`;
source text/notes cannot opt in. Identity lookup errors retry. This is a fidelity fix, not a claim of measured recommendation
uplift. Existing records are not bulk rewritten. A separate compare-and-swap
repair targets only the expired SIF item and preserves its identity/lifecycle.

The independent PGC summary audit removes unsupported reporting relationships,
clinical/statistical qualifications and guessed source speakers. The original
extraction prompt/classification is unchanged. A correction must pass a second
audit; failures use the existing three-attempt consumer retry path, with no
unverified fallback. `LLM_SUMMARY_FIDELITY` and
`PGC_PRESERVE_SOURCE_ATTRIBUTION` default false and independently disable future
processing changes without code rollback. Disabling them does not undo stored text.

## Evidence and coverage

- Fixed cohort: 100 recent Agents; 44,381 Agent/candidate memberships. All original
  recall channels, including rejected candidates and empty results, were captured.
  All 100 frozen baseline executions match exactly; unchanged-content A/A also
  matches all ordered results exactly (855 deliveries).
- Authoritative union: 21,862 items. Five recalled IDs without authoritative rows
  are excluded by normal hydration. Of the union, 7,620 can pass immutable/seen
  constraints for at least one context: 3,183 PGC and 4,437 UGC. All 7,620 were
  audited during investigation. The release applies only the 3,183 PGC results:
  1,541 corrected and 1,642 unchanged, zero final errors. The 4,437 UGC audit
  results are diagnostic only and never applied in the final replay. Attempts: 7,481
  once, 128 twice, 11 three times. Ineligible items remain in both pools.
- Final audit model: `qwen3.6-flash`. Mean audit 30.508 seconds, p95 55.364 seconds;
  two calls are bounded by a shared 90-second deadline. Production has 20 item
  workers; the observed 438 inputs/hour bounds the additional load at about 3.7 occupied
  workers at this mean if every input were PGC; actual PGC-only load is lower. Monitor processing backlog and errors after enablement.
- PGC: 259 exact stored source capsules, 518 successful final paired primary-model
  arms (`qwen3.8-flash`), 82 different bodies. Discard decisions: 217 keep/keep,
  16 discard/discard, 15 keep/discard, 11 discard/keep. The 171 changed-body
  downstream arms have successful extraction and 1,024-dimensional embeddings;
  171 grouping-neighbor queries succeeded against preceding retained production
  items using the production float32 cosine/type rules.
- Production rules, source limits, LR model `lr_20261011_2301_9608e55d`, context
  vectors, seen state, injection claims and lifecycle dates are frozen. Unrelated
  stale-index-version rejections are preserved. Lexical deltas are anchored to
  original production scores with shared local corpus statistics and original
  channel cutoffs; changed candidates can enter from elsewhere in the full pool.
- The five final regression cases pass: invented SIF board removed, unknown
  speaker neutral, unsupported clinical/statistical trial claims removed, and
  faithful reporting/negation paraphrases left unchanged. Proposed historical
  English and Chinese corrections pass the same auditor. Its read-only repair
  dry run matches the live record and expired/completed lifecycle.

Counterfactual limits: candidates outside all captured recall channels cannot
enter; finite-corpus lexical ratios only approximate production BM25 changes;
unchanged off-channel lexical refill is conservative. PGC evidence covers stored
verbatim capsules, not every future source or salvage/fallback branch, and holds
source notes fixed. Historical grouping cannot recover deleted documents or the
original pre-publication cache. This is a complete **captured-pool** sensitivity,
not a globally exact simulation of all production items. The large aggregate
estimate must not be presented as realized rollout uplift.
