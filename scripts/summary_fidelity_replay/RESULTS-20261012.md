## Findings and unmet acceptance criteria

- The real source case preserves its named leaders and reporting targets, without
  inventing a board. The current model also avoided a board with the old prompt;
  the historical bad output was not reproduced in this small current-model run.
- The unknown-speaker fixture uses neutral source attribution when enabled. The
  old prompt called the forwarding broadcaster the actor and added collaboration
  implications absent from the source.
- **The negation fixture still adds “clinical”, which the source does not say.**
  An earlier candidate also added statistical significance. The final instructions
  removed the significance addition in this sample but did not eliminate all
  unsupported specificity. This prompt-only candidate is not a complete fix and
  must not be enabled on the strength of transport/unit-test success.
- Ranking fields (keywords/quality) vary between paired calls. That may include
  ordinary model variability; distribution invariance has not been established.
